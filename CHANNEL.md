# Your channel

Claude reads this before planning any video. Fill it in, or tell Claude "set up my channel" and it will ask you.
The default hard rules in `SKILL.md` ("Your channel") always apply; add stricter ones here.

| | |
|---|---|
| Niche | _e.g. practical AI for small-business owners_ |
| Audience | _who watches, and what they do all day_ |
| Tone | _e.g. a coworker showing something useful, not a hype creator_ |
| Words per second | _leave blank: the script check measures it from your first test clip_ |
| CTA keywords in use | _e.g. SKILL → the free skill; keep one keyword per lead magnet_ |
